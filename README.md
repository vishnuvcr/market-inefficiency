# Market Inefficiency Research Lab

This repository is an experimental research program for identifying, testing, validating, and stress-testing structural inefficiencies in Indian derivatives markets.

The research protocol is maintained on the active research branch. The main branch is kept as the stable integration point.

## Research governance

- No strategy is considered valid from a backtest alone.
- Every experiment must have a hypothesis ID, dataset version, time split, transaction-cost model, and leakage controls.
- Multiple-testing adjustments and out-of-sample validation are mandatory before any deployment decision.
- Results are recorded reproducibly in GitHub Actions artifacts and committed research reports.
